In _write_changes, file changes are written to disk and staged using raw, un-normalized path strings from change["path"]. If an AI-generated change path contains path traversal components or un-normalized slashes, using raw path strings directly in open() and git add can interact unexpectedly with symlinks. Normalizing path with _norm(change["path"]) before filesystem and git operations ensures file writes stay within the repository working tree.
