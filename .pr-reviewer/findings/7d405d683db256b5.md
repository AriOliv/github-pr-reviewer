In `open_pr`, file changes are written to disk and staged using raw, un-normalized paths from `change["path"]`. If an AI-generated change path contains relative path traversal components (`..`), using raw path strings directly in `open()` and `git add` can resolve differently than intended or interact with symlinks. Normalizing the path with `_norm(change["path"])` prior to filesystem and git operations ensures file writes stay within the repository working tree.
